# Life Balance - Sistema de Treinos

Aplicação web simples para:

- Login de professor e login de alunos.
- Cadastro de alunos pelo professor.
- Cadastro de treinos com link de vídeo do YouTube.
- Visualização de treinos: professor vê todos e aluno vê apenas os próprios.

## Como executar

```bash
python3 -m http.server 8000
```

Depois abra `http://localhost:8000`.

## Usuários iniciais

- Professor: `professor` / `1234`
- Aluno: `aluno1` / `1234`
